### 👨‍💻 About me

I build the data stack **end to end**: ingesting data from APIs and ERPs, modeling it in the warehouse and delivering it as semantic layers, dashboards and data apps.

```yaml
role:        Analytics Engineer
focus:       [data pipelines, data modeling, semantic layers, BI]
currently:   Airflow 3 · dbt · BigQuery · LookML
believes_in: "one source of truth, documented metrics"
```

### ⚙️ What I'm building

| | |
|---|---|
| 🔄 **Ingestion** | Airflow 3 (Astronomer) DAGs pulling e-commerce, marketplace and ERP APIs into GCS & BigQuery |
| 🧱 **Modeling** | dbt on BigQuery, orchestrated with Astronomer Cosmos |
| 🧭 **Semantic layer** | LookML models for Sales, Finance, Inventory, Marketing, CX and market data, plus Cube.js over ERP data |
| 📊 **Delivery** | Looker, Looker Studio and Power BI dashboards; Streamlit apps on Cloud Run |
| 🤖 **AI-assisted** | Claude Code agents to speed up engineering and documentation |
